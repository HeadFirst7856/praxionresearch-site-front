What Praxion Is Building

The next stage of the site is meant to present Praxion as a serious research and execution shop, not a generic brochure. We want a clear public face up front, then a private operator dashboard behind login for the team.

Strategy Research

Develop and rank live-viable strategies with an emphasis on robustness, operational simplicity, and real-world deployability.

Execution Infrastructure

Bridge signal generation into broker-specific execution with shared credentials, logging, heartbeats, kill switches, and clean deployment paths.

Live Benchmarking

Benchmark live-traded and shadow strategies side by side so decisions are based on current reality, not stale backtest narratives.

Execution Stack

The current private runtime direction already includes TopstepX and IBKR deployment folders, shared credentials, Telegram heartbeats, JSONL runtime logs, and strategy-specific runtime state. The site can sit directly on top of that log stream once the dashboard backend is wired.

TopstepX

Live scaffolds for funded / combine-style monitoring, with supervised process restarts and Telegram status updates.

IBKR

Parallel deployment path for broker-specific execution and long-run benchmarking once the live stack stabilizes.

Operator Loop

Heartbeats, trade-event logs, kill-switches, and strategy-by-strategy visibility so the operating surface stays clean under pressure.
